## 本轮二：报错分析容错归一化 + --rules（commit b3f2774）

### 1. normalize_text()：报错文本归一化
**问题**：`analyze_text` 是精确子串匹配，用户从截图 OCR、跨行排版粘过来的报错
经常匹配不上——关键词里的空格在原文里是换行。
归一化五件事：
1. 全角字母/数字/标点 → 半角（U+FF01..U+FF5E 减 0xFEE0）
2. 全角空格 U+3000 → 半角空格
3. 丢零宽字符（U+200B/200C/200D/FEFF）与软连字符 U+00AD
4. 所有空白（含换行/制表/回车）压成单个空格，去首尾
5. ASCII 大写转小写（**含全角转半角后的**）

⚠️ 第一次实现漏了第 5 条的「全角分支也要小写化」，导致
`Ａｃｃｅｓｓ` → `ACCess` 而不是 `access`，匹配不上。补上后 8 类容错全过。

实测通过：跨行断词 / 全角字母+全角空格 / 零宽字符 / 软连字符 /
制表+多空格 / 全角错误码（０ｘ８００７００２０ → 0x80070020）/ 换行+全角混合 / 正常文本

### 2. --rules 列出规则库
一条命令看全 34 条的触发词、适用平台、对策——既是文档也是规则库自查入口。

## 教训
- **C 里 `"\xc2\xad"` 的 `\x` 会贪婪吃十六进制位**：写成 `"\xc2\xader"` 会被解析成
  `\xc2ade` 一个转义，必须断开写 `"\\xc2\\xad" "er"`。测试自己写错了两次才发现
- **转换类函数要记得「转完再做后续处理」**：全角转半角后忘了小写化，就是典型的漏一步
